# zenfmt 0.3.6

zenfmt 0.3.6 updates the embedded secure-mode storage dependency and corrects
XLSX custom date formatting while keeping the CLI, Python API, browser API, HTTP
API, and document schemas compatible with 0.3.5.

## Excel date columns

- XLSX cells using custom date number formats now render as ISO dates in
  Markdown instead of exposing Excel serial numbers.
- Built-in date and percentage formats retain their existing behavior; custom
  percentage formats now resolve through the same style table.
- Format classification ignores quoted, escaped, color, condition, and locale
  literals so display text is not mistaken for a date token.

## Storage dependency

- The pinned zaxonlite dependency advances from 0.3.0 to 0.6.0.
- Secure-mode storage now incorporates zaxonlite's lifetime-global Paxos slots,
  bounded reusable consensus window, continuous segmented-journal trimming,
  durable state anchors, and beyond-retention replica transfer.
- zenfmt continues to use zaxonlite in embedded single-node mode; this release
  does not enable multi-node zenfmt replication or change the zenfmt storage
  schema.

## Compatibility

- Existing manifests, server endpoints, and secure-mode account data remain
  compatible.
- The native CLI and server remain one self-contained executable. No separate
  zaxonlite installation or runtime service is required.

## Upgrade

Replace the 0.3.5 executable with 0.3.6 and restart a running service. Back up
the secure-mode data directory before upgrading, as for any storage dependency
update. Web applications may install `@insanai/zenfmt@0.3.6`.
