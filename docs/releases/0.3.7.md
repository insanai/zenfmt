# zenfmt 0.3.7

zenfmt 0.3.7 preserves time-bearing XLSX values and repairs typed Python
access to manifest facets while keeping the CLI, browser API, HTTP API, and
document schemas compatible with 0.3.6.

## Excel date and time values

- XLSX cells formatted as date-times now retain their time component and
  render as normalized `YYYY-MM-DD HH:MM:SS` values.
- Time-only cells render as `HH:MM:SS` instead of exposing an Excel
  fractional-day serial.
- Built-in and custom formats distinguish dates, date-times, clock times, and
  elapsed times. Elapsed formats such as `[h]:mm` retain hours beyond 24.
- Serial fractions are rounded to the nearest second so common spreadsheet
  encodings round-trip without floating-point artifacts.

## Python manifest facets

- `Manifest.facets` now matches manifest schema version 2: it returns a
  defensive mapping keyed by facet kind rather than incorrectly requiring an
  object array.
- Summary facets are accessible with the default conversion settings, and
  full rows are accessible when `preserve_facets=True`.
- Malformed native facet envelopes continue to raise `NativeLibraryError`.

## Compatibility and performance

- Existing manifests, server endpoints, native APIs, and browser APIs remain
  compatible.
- Alternating 101-iteration XLSX benchmark trials showed an unchanged median
  full-conversion latency of 0.368 ms before and after the fix.

## Upgrade

Replace the 0.3.6 executable with 0.3.7 and restart a running service. Python
applications may upgrade to `zenfmt==0.3.7`; web applications may install
`@insanai/zenfmt@0.3.7`.
